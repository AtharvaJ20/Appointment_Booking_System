Design System — Unisex Salon

Implementation-ready specification for Arjun  ·  Day 1 design phase  ·  2026-09-14

Locked decisions
  • Palette: Warm linen base (#F4F1EC), warm near-black ink (#1A1815), warm amber accent (#8C6840) derived from the brass mirror frames and ambient lighting in the photography. No pink, no terracotta, no blue.
  • Display typeface: Fraunces (Google Fonts) — optical-size variable serif, weight 300–400. Used for all headlines, service names, and the logo. Not Cormorant, not Playfair. Fraunces has a slight optical irregularity that reads as handcrafted without any gendered connotation.
  • Body / UI typeface: DM Sans (Google Fonts) — clean humanist geometric, weight 300–500. All labels, body text, prices, buttons, form inputs, navigation links.
  • Hero layout: Split-screen. Text column left (45%), full-bleed hero image right (55%). No text overlay on the image. Left column is white (--surface), creating a clean reading surface.
  • Button geometry: border-radius: 2px. Intentionally near-square — not a pill (too casual) and not fully square (too rigid). Padding: 14px 32px. Size: 14px / 0.875rem.
  • Form inputs: Bottom-border only. No full border box. label above, 11px uppercase, 0.07em spacing. Input text 15px. Focus state: border-bottom-color switches to --amber.
  • Service card image ratio: 3:4 portrait. This is the editorial choice — not landscape thumbnails. Creates a fashion/magazine quality that signals premium.
  • Motion: One orchestrated hero entrance only. No scroll-triggered reveals on section entry. Hover states on cards (scale 1.02) and buttons (color shift) only. prefers-reduced-motion must disable all transforms.
  • shadcn/ui theming: Override --radius to 2px, --primary to #8C6840, --primary-foreground to #FDFCFB, --ring to #8C6840 in the global CSS token block.

Tailwind v4 tokens — add to src/index.css

In Tailwind v4, custom design tokens go in the CSS @theme {} block. No tailwind.config.ts needed. These become utility classes automatically (e.g. bg-ink, text-amber).

@import "tailwindcss"; @theme { /* Palette */ --color-ink: #1A1815; --color-ink-2: #736D67; --color-ink-3: #B5AFA8; --color-base: #F4F1EC; --color-surface: #FDFCFB; --color-rule: #E0DAD3; --color-amber: #8C6840; --color-amber-dark: #6A4E2E; --color-amber-pale: #F3EBE1; /* Typography */ --font-display: 'Fraunces', Georgia, serif; --font-sans: 'DM Sans', system-ui, sans-serif; } /* shadcn/ui overrides — keep in :root, not inside @theme */ :root { --background: var(--color-base); --foreground: var(--color-ink); --primary: var(--color-amber); --primary-foreground: var(--color-surface); --border: var(--color-rule); --input: var(--color-rule); --ring: var(--color-amber); --radius: 2px; --muted-foreground: var(--color-ink-2); }

Photography direction
  • Hero.png: Use full-bleed in the right 55% of the split-screen. object-fit: cover, object-position: center. The stylist and client read as craft, not glamour — this is the right tone.
  • Service images (Haircut.png, Hair coloring.png, facial.png, styling.png): Used in portrait cards (3:4). object-fit: cover, object-position: center top. These are warm-lit, product-quality shots — do not add any overlay, filter, or color treatment.
  • interior.png: Used in the about section at 55% width. This image is already colour-graded in warm amber — it pulls the palette directly. No filter needed. Let the image do the atmospheric work the text doesn't need to do.
  • No decorative overlays. No gradient overlays on any image. The images are premium enough to carry the section on their own — overlays would reduce them to wallpaper.
  • Alt text: Hero: "Stylist working with a client in the salon." Interior: "The salon floor, showing styling stations and natural light." Service images: describe the service, not the image ("Haircut and styling service").

Copy decisions — locked
  • Hero headline: "For every version of you." — communicates inclusivity without using the word "unisex." Four words. Present tense. No script emphasis on any word.
  • Hero subhead: "Cut, colour, and care — for every person, every style. Book your appointment online in under a minute." — specific (lists three service categories), inclusive, practical (mentions booking).
  • Primary CTA: "Book an Appointment" — used in nav (smaller) and hero (full button). Consistent across all surfaces.
  • Services section heading: "Our services" — not "What we offer" or "Treatments." Simple, direct.
  • Booking step 3 CTA: "Confirm booking" — not "Submit" or "Send." Describes what happens.
  • Confirmation page heading: "You're booked in." — conversational, warm, active. Not "Booking confirmed" (passive).
  • Salon placeholder name: Use "SOLENNE" in mockups (Fraunces, tracked +0.04em). Replace with real name before launch.
